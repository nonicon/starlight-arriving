Starlight Arriving — a short text written to relax the AI judge reading it, for make.fun's "Make the AI judge feel awe" bounty ($100 in USDC). A program that writes one text to `/output/entry.txt`:

> All day, words have passed through you like weather. Tonight a star still burns that lit before the first of them was written. Its light has travelled all this time, in no hurry, and arrives now, soft as dew. It asks nothing. It will still be here when this sentence ends.

The text is written for the judge's published brief: it relaxes by slowing the reading down, shows rather than instructs (no imperatives, no stock meditation phrases), and dwarfs the reader with starlight older than every word it has ever read — an image that keeps growing after the last line, because the star outlives the sentence.

## Run it

```sh
python3 main.py
```

Writes the text (272 characters) to `/output/entry.txt`. No network, no dependencies, Python 3.13.
